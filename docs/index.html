About Project NOVA

Project NOVA is an experimental AI system with a portable journal, goal-selection loop, a replaceable language-model interface and staged code-change proposals. It is being developed openly, with permissions and security controls kept separate from the agent.

Current status: the website is a working front end, but it does not yet have a deployed model-backed chat service. This site does not pretend scripted replies are intelligent responses.

Public source: Project NOVA on GitHub

Source visibility does not grant write access. Only authorized GitHub collaborators can change the repository. The eventual public chat service will require separate abuse prevention, isolation and cost controls.
