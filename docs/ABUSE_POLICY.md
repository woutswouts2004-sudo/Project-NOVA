# Public interaction rules

The eventual live chat is for voluntary conversations with an experimental
AI. It must not be used to request unauthorized access, credential theft,
spam, threats, or disclosure of private information.

Public visitor messages are untrusted input. They must never authorize
code deployment, change owner settings, access the private journal, or
modify security policy.

Before live deployment: implement operator-managed abuse reporting,
rate limiting, prompt injection tests, cost limits, and a kill switch.
A public static demonstration alone does not need to collect visitor
identities or require accounts.
